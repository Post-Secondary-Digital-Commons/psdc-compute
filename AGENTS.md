# Agent instructions for psdc-compute

The Compute fabric owns workload placement, provider capabilities, leases, and compute evidence.

Before assessing or editing this repository, read [the skill manifest](.psdc/agent-skills.yaml) and its pinned common skill policy. Start at [README.md](README.md) and [docs/architecture/00-overview.md](docs/architecture/00-overview.md). Use the PSDC project assessment rubric for readiness claims and the evidence audit for claims about tests or deployment.

Shared decisions and contracts belong to `psdc-architecture`; propose changes there before changing a common interface here. This repository's change scope is its own checkout. Keep institution branding, secrets, topology, and deployment policy in institution overlays. A documentation or schema check supports structural evidence only.
